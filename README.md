# 📝 Text_2_Image Tampermonkey脚本

一款能將網頁文字輕鬆轉換為精美分享卡片的工具。
A simple tool to transform webpage text into beautiful sharing cards.

---

## 📖 產品簡介 / Introduction
**Text_2_Image** 旨在簡化資訊分享的流程。無論是名言佳句還是新聞摘要，只需用滑鼠選取文字，即可快速生成視覺美觀的卡片。

To easily share webpage text content, simply select the text with your mouse to create a sharing card.
要輕鬆分享網頁文字內容，只需用滑鼠選擇文字即可建立分享卡片。
